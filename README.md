# badass-connector
Open-source connector for securely testing private and local AI applications with BADASS.

BADASS Connector is the open-source agent that connects private AI applications to the BADASS security testing platform.

It enables testing of AI systems running on localhost, Docker, internal networks, private cloud environments, and authenticated APIs without sending credentials, API keys, cookies, or authentication headers to BADASS Cloud by default.

The connector performs local validation, traffic recording, attack execution, and result sanitization before transmitting security findings back to the BADASS platform.
